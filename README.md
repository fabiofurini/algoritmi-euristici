# Algoritmi euristici

Le dispense di algoritmi euristici per i problemi di ottimizzazione combinatoria: bound primali e duali e valutazione delle euristiche, euristiche costruttive, ricerca locale, metaeuristiche (simulated annealing, tabu search, iterated local search, variable neighbourhood search, GRASP, large neighbourhood search, algoritmi genetici) ed euristiche MIP, applicate a zaino, bin packing, commesso viaggiatore, scheduling su macchine parallele e colorazione dei vertici. Con esercizi svolti, slide, app interattive e notebook Colab (Python e C++).

**Sito: [fabiofurini.github.io/algoritmi-euristici](https://fabiofurini.github.io/algoritmi-euristici/)**

Prerequisiti: [Problemi di ottimizzazione combinatoria](https://fabiofurini.github.io/ottimizzazione-combinatoria/) (i problemi, le loro istanze e le loro formulazioni).

Un corso della collana *Ricerca Operativa e Matematica* di [Fabio Furini](https://fabiofurini.github.io/) (DIAG, Sapienza Università di Roma). Contenuti CC BY 4.0, codice MIT.
